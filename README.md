# AI Chatbot 
A simple AI chatbot built using Python and Google Gemini API. 
## Features - Gemini API integration - Chat session - User prompts - System instructions - Conversation history - Error handling 
## Technologies Used - Python - Google Gemini API - google-genai - python-dotenv 
## Installation 
Clone the repository: 
git clone YOUR_GITHUB_REPOSITORY_URL 
Install dependencies: 
pip install -r requirements.txt 
Create a `.env` file: 
GEMINI_API_KEY=YOUR_API_KEY 
Run the application: 
python main.py
